# Контекст проекта ege-math

Этот документ читается перед началом работы согласно `AGENTS.md`. Он хранит решения, которые нельзя терять между сессиями Codex. Обновляйте его вместе с изменениями, затрагивающими перечисленные ниже факты.

## Назначение и устройство

- Проект — сайт с заданиями профильной математики и физики ЕГЭ из открытого банка ФИПИ и развёрнутыми решениями.
- Сервер: `server.js`; данные решений: `storage/solutions.sqlite`; исходные выгрузки ФИПИ: файлы `*.raw.html` в корне.
- Разделы: стереометрия, планиметрия, параметры, уравнения, неравенства, оптимальный выбор, числа и финансовая математика.
- Для дробей в текстах решений используется только запись `⟦числитель¦знаменатель⟧`. HTML в решения вручную не добавляется.
- Форматтер поддерживает индекс после ℰ, например `ℰ_си`. Множители после буквенного индекса отделять пробелом или знаком умножения: `I_V · R_р`, не `I_VR_р`. Регрессии: `node --test scripts/math-rendering.test.js`.
- Составные корни `√(…)` разбираются по сбалансированным скобкам, включая вложенные скобки, дроби и корни; краткая запись `√14v` по-прежнему означает `√14 · v`. Исходные тексты не переписываются. До публикации проверены все затронутые страницы: десять новых электродинамических и 16 прежних; регрессионные тесты защищают область корня, индексы и экранирование HTML.

## Классификация заданий

- Состав разделов математики и тем физики задаёт серверная функция `filterSectionHtml` в `server.js`. Она применяется до формирования каталогов; базовые разделы также используются поиском, sitemap и страницами заданий. Клиент только разбивает уже выбранные задачи на страницы.
- Не возвращать фильтрацию состава разделов в клиентский код: иначе каталог, поиск и отдельные страницы снова начнут расходиться.
- Темы физики задаются `lib/physics-topics.js`: исходные КЭС дополняются отдельной проверенной разметкой `lib/physics-topic-overrides.json`. Основная тема определяет заголовок, хлебные крошки и навигацию; основная и дополнительные темы используются каталогами и счётчиками. Исходные HTML не переписывать. При изменении КЭС или SHA-256 условия ручная правка получает статус `stale`, не применяется сервером и блокирует аудит до повторной проверки.
- На текущем снимке ФИПИ математический каталог содержит 445 уникальных заданий: стереометрия — 66, планиметрия — 75, параметры — 57, уравнения — 67, неравенства — 63, числа — 51, финансы — 64, оптимальный выбор — 2. Эти числа изменятся после обновления выгрузки, поэтому при обновлении источников их нужно перепроверять.
- Задачи с КЭС 7.1, у которых есть КЭС 7.2, 7.3 или 7.4, относятся к стереометрии и не попадают в планиметрию.
- Семантические кредитные задачи, ошибочно попавшие ФИПИ в выгрузки уравнений или чисел, дополняют финансовый раздел. Не убирать это дополнение: иначе опубликованное решение `F4D70D` становится недоступным.
- Задачи о свойствах чисел с дополнительной КЭС 2.10 остаются в разделе «Числа», а не дублируются в параметрах.
- Параметр `section` разрешён только маршрутам `/added` и `/update`; обычные адреса каталогов не должны менять раздел через строку запроса.

## Стандарт подробного решения

- Для каждой физической задачи действует универсальный промпт: сверить условие и рисунок ФИПИ с `phys-ege.sdamgia.ru`, составить самостоятельный развёрнутый вывод, задать оси и силы до записи законов, синхронизировать обозначения текста и схемы, сохранить исходную геометрию, выполнить аудит и визуальную проверку скриншотом перед публикацией.
- Численные вычисления в физических решениях оформляются последовательно: сначала общая формула/уравнение, затем отдельная подстановка данных с единицами и итоговое вычисление.

- Не допускать скачков вида «из направляющего вектора сразу получили уравнение прямой». Сначала задать произвольную точку прямой через параметр, затем исключить параметр.
- Для уравнения плоскости явно показать: точку плоскости, направляющие векторы, условия перпендикулярности нормали, решение системы и равенство `n·(X−P)=0` для произвольной точки X плоскости.
- В `FAAE63` уже добавлен параметрический вывод уравнения прямой CM.
- В `0B28A5`, `1F7CE6` и `F416AF` уже добавлен развёрнутый вывод уравнения плоскости через нормаль и точку. В `1F7CE6` исправлен знак в скалярном произведении.
- Перед публикацией сверять условие, ответ и ключевой ход с ФИПИ и независимо с «Решу ЕГЭ» согласно `AGENTS.md`.
- По запросу пользователя 22.09.2026 Turnstile временно отключён для регистрации, входа пользователя и администратора, комментариев и форм обратной связи. Переключатель `TURNSTILE_ENABLED=0` задан отдельным systemd drop-in; автоматически защиту обратно не включать без запроса пользователя. В коде защита включена по умолчанию и отключается только явным значением `0`: одновременно убираются виджет/скрипт и серверная проверка токена. Значения `TURNSTILE_SECRET_KEY` и `TURNSTILE_SITE_KEY` сохранены во внешнем `EnvironmentFile` сервиса; секрет нельзя помещать в репозиторий, документацию или логи. При включённой защите обязательны проверка hostname и отказ при ошибках/отсутствии ключа.
