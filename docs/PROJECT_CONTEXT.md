# Контекст проекта ege-math

Этот документ читается перед началом работы согласно `AGENTS.md`. Он хранит решения, которые нельзя терять между сессиями Codex. Обновляйте его вместе с изменениями, затрагивающими перечисленные ниже факты.

## Назначение и устройство

- Проект — сайт с заданиями профильной математики ЕГЭ из открытого банка ФИПИ и развёрнутыми решениями.
- Сервер: `server.js`; данные решений: `storage/solutions.sqlite`; исходные выгрузки ФИПИ: файлы `*.raw.html` в корне.
- Разделы: стереометрия, планиметрия, параметры, уравнения, неравенства, оптимальный выбор, числа и финансовая математика.
- Для дробей в текстах решений используется только запись `⟦числитель¦знаменатель⟧`. HTML в решения вручную не добавляется.

## Классификация заданий

- Единственный источник фильтрации — серверная функция `filterSectionHtml` в `server.js`. Она применяется до формирования каталога, поиска, sitemap и страницы задания.
- Не возвращать фильтрацию в клиентский код: иначе каталог, поиск и отдельные страницы снова начнут расходиться.
- На текущем снимке ФИПИ каталог содержит 445 уникальных заданий: стереометрия — 66, планиметрия — 75, параметры — 57, уравнения — 67, неравенства — 63, числа — 51, финансы — 64, оптимальный выбор — 2. Эти числа изменятся после обновления выгрузки, поэтому при обновлении источников их нужно перепроверять.
- Задачи с КЭС 7.1, у которых есть КЭС 7.2, 7.3 или 7.4, относятся к стереометрии и не попадают в планиметрию.
- Семантические кредитные задачи, ошибочно попавшие ФИПИ в выгрузки уравнений или чисел, дополняют финансовый раздел. Не убирать это дополнение: иначе опубликованное решение `F4D70D` становится недоступным.
- Задачи о свойствах чисел с дополнительной КЭС 2.10 остаются в разделе «Числа», а не дублируются в параметрах.
- Параметр `section` разрешён только маршрутам `/added` и `/update`; обычные адреса каталогов не должны менять раздел через строку запроса.

## Стандарт подробного решения

- Не допускать скачков вида «из направляющего вектора сразу получили уравнение прямой». Сначала задать произвольную точку прямой через параметр, затем исключить параметр.
- Для уравнения плоскости явно показать: точку плоскости, направляющие векторы, условия перпендикулярности нормали, решение системы и равенство `n·(X−P)=0` для произвольной точки X плоскости.
- В `FAAE63` уже добавлен параметрический вывод уравнения прямой CM.
- В `0B28A5`, `1F7CE6` и `F416AF` уже добавлен развёрнутый вывод уравнения плоскости через нормаль и точку. В `1F7CE6` исправлен знак в скалярном произведении.
- Перед публикацией сверять условие, ответ и ключевой ход с ФИПИ и независимо с «Решу ЕГЭ» согласно `AGENTS.md`.
- Turnstile включён для регистрации, входа пользователя и администратора, комментариев и форм обратной связи. Значения `TURNSTILE_SECRET_KEY` и `TURNSTILE_SITE_KEY` задаются только внешним `EnvironmentFile` сервиса; секрет нельзя помещать в репозиторий, документацию или логи. Сервер проверяет hostname ответа.

## Скрипты и проверки

- `npm run audit:solutions` — общая проверка опубликованных решений, формата, схем и уравнений.
- `npm run check:planimetry` — проверка 15 расширенных решений планиметрии; обновление: `npm run expand:planimetry`.
- `npm run check:planes` — проверка пояснений к уравнениям плоскостей; обновление: `npm run clarify:planes`.
- После изменения каталога проверить все публичные разделы, отсутствие дубликатов в sitemap, доступность опубликованных решений по `/tasks/{ID}` и выполнить `git diff --check`.

## Текущее состояние

- Фильтрации перенесены с клиента на сервер и проверены: в sitemap нет повторяющихся идентификаторов, все 445 заданий имеют опубликованные решения.
- Недостающие решения публикуются воспроизводимым скриптом `scripts/publish-missing-solutions.js`: пакет содержит 73 обновления (48 заданий по числам, 19 по финансовой математике и 6 по стереометрии). Для стереометрии в базе сохраняются SVG-схемы.
- Решения и обновляющие их скрипты являются единым изменением: не редактировать только базу, если изменение можно закрепить в скрипте.
- При независимой сверке с «Решу ЕГЭ» исправлены решения по числам `002FC3` (пункт а), `9BC08F` (учтено число 600 в пункте в) и `A0A7EB` (пункты а и б). Эти правки хранятся в `scripts/publish-missing-solutions.js` и применены к опубликованной базе.
- Все 51 решения раздела «Числа и их свойства» расширены: явно приведены формулы преобразований, разбор случаев, оценки и достигающие примеры; отдельно добавлены четыре ранее коротких записи (`F37F75`, `6FF25E`, `A87FAB`, `E8AA65`). Формат исходного текста остаётся обычным текстом с дробями `⟦…¦…⟧`.
- В навигации шапки добавлена крупная акцентная кнопка «Физика» со ссылкой `/physics`; оформление продублировано для каталога и страницы «О проекте».
- Маршрут `/physics` открывает отдельное меню только для заданий с развёрнутым ответом (№27–30): качественная задача, механика, молекулярная физика и термодинамика, электродинамика. Структура сверена с тематическими блоками «Решу ЕГЭ — физика».
- Внутри каталога физики общая шапочная навигация не показывает математические разделы: остаются только ссылки физического раздела и его добавленных задач; на математических страницах физика доступна отдельной верхней кнопкой.
- Пункты меню типов физики не скрываются клиентским фильтром при нулевом/не распознанном счётчике: меню должно оставаться постоянным после загрузки страницы.
