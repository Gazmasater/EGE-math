Точный числовой вариант этих четырёх задач не найден. Их ответы проверены отдельно обратным энергетическим балансом и, где нужно, условием сохранения двух фаз.
- В №5376 и №38961 замечены дефекты символьной записи источника; они не перенесены в авторские решения. У B4D4B9 учтена именно медь, а не железо из аналога; удельная теплоёмкость меди дополнительно сверена с №25242.
- В исходных условиях новых 16 задач нет рисунков. Созданы собственные SVG-схемы стадий теплообмена; стрелки не обозначают силы. Для чисто тепловых задач объяснено, почему координатные оси и проекции сил не используются.

## Повторный запуск

`npm run audit:thermal` проверяет опубликованный пакет и состав раздела. `npm run publish:thermal` применяет только 16 записей идемпотентно. Для копии SQLite использовать `--db ПУТЬ`. `npm run check:thermal:pages` проверяет браузер; `PHYSICS_DB` указывает базу для сверки отметок каталога при предпросмотре, не меняя базу сервера. Общее `npm run audit:physics` включает новый пакет.

Оставшиеся ID перечислены со статусом `pending` в `scripts/data/thermal-catalog.json`; их решения этим пакетом не создаются и не публикуются.
