# Согласованная очистка сервера — 22.09.2026

После осмотра пользователь согласовал три категории: кэши APT/Node.js/Snap, две отключённые версии Snap и два временных профиля браузерных проверок. Системные журналы, пользовательские файлы, исходники, изображения задач, базы и прежние резервные копии исключены из очистки.

## Удалено

- Только ревизии `chromium/3529` и `core24/1643`, штатными командами `snap remove … --revision=…`. Текущие `chromium/3530` и `core24/2124` и все остальные установленные версии сохранены.
- `/var/cache/apt/pkgcache.bin` и `/var/cache/apt/srcpkgcache.bin` — пересоздаваемые индексы APT.
- Шесть проверенных файлов в `/var/lib/snapd/cache`. Жёсткие ссылки на установленные образы учтены: сами действующие образы не удалены.
- Содержимое `/tmp/node-compile-cache`. Кэш может появиться снова при работе Node.js; после проверок уже пересоздалось около 504 КиБ.
- Неиспользуемые профили `/tmp/thermal-browser-GTR2oC` и `/tmp/electrodynamics-browser-rwlgE8`. Перед удалением проверены процессы и открытые файлы через `lsof`; символические ссылки удалялись без перехода к их целям.

Настройки старой ревизии Chromium и каталоги данных удаляемых ревизий предварительно сохранены в `old-snap-revision-data.tar.gz`, права `0600`, целостность gzip проверена. Общий профиль Chromium и данные текущей ревизии не менялись. Автоматические снимки Snap не создавались.
