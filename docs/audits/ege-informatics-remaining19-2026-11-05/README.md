# Восемь условных разборов из оставшихся 19

На 05.11.2026 опубликованы 2456 из 2475 решений ЕГЭ по информатике. Эта проверка не добавляет опубликованных ответов. [Восемь подробных разборов](conditional-drafts.json) содержат исходные условия, собственные алгоритмы, доказательства, код, условные результаты и точное указание недостающих данных. Поле `answer` в каждом равно `null`; файлы не подключены к реестру решений.

## Четыре контрпримера с одновременными заявками

В первом расчёте заявки сортируются по времени начала с сохранением порядка строк при равенстве. Во втором меняются местами только две соседние заявки внутри одного времени. Условие не определяет, в каком порядке их обрабатывать. В обоих случаях место выбирается с минимальным номером, повторное использование разрешено строго после минуты окончания обслуживания.

| Задача | Ответ при порядке строк | После одной перестановки | Минута | Строки исходного файла |
| --- | --- | --- | ---: | --- |
| 290F15 | 340 53 | 339 53 | 603 | 17 и 768 |
| B3C563 | 361 83 | 360 83 | 616 | 839 и 913 |
| A99635 | 380 133 | 379 133 | 620 | 286 и 395 |
| 8ECB7C | 784 3 | 784 2 | 3 | 531 и 871 |

Номер строки учитывает две строки заголовка. Это демонстрация неоднозначности, а не таблица рекомендуемых ответов. Для каждой задачи также рассчитаны варианты с возрастанием и убыванием времени окончания внутри равных времён начала. Python использует две очереди с приоритетом, JavaScript напрямую перебирает места. Совпали все назначения каждой заявки в 16 расчётах, а не только итоговые числа. [Python](python-review.json), [независимая сверка](independent-review.json).

## Четыре несоответствующих вложения

- **CE2CF3:** заявлены буквы A, B, C, D, U, файл содержит A, C, D, E, F. Весь архив совпадает с сохранённым вложением **2F6892**, в условии которого другой алфавит и обратный порядок пары. Сохранён [фрагмент условия 2F6892](2F6892-source-fragment.json); контрольные суммы и происхождение — в [манифесте](manifest.json). При алфавите самого файла цепочка «согласная + гласная» достигает 97 пар; механическое применение множеств букв из условия даёт 11. Оба результата условные. Само дублирование не устанавливает, каким должен быть правильный файл CE2CF3.
- **1F25B2:** требуется список размеров коробок, приложена строка букв `331_24.txt`. Расширение `.zip` скрывает RAR; архив исправен, но данные не подходят. Подготовлен жадный алгоритм с доказательством максимума обоих критериев; 500 небольших наборов сверены с полным перебором подмножеств.
- **7F1EAA:** требуются пары «ряд, место», приложены две одномерные числовые последовательности. Подготовлен алгоритм поиска разрывов ровно на три между соседними занятыми местами; проверены пример и все 1023 непустых набора занятых мест на десяти позициях.
- **327EB5:** вместо одного N заголовки содержат `100 113` и `1200000 12013`. Значение дополнительного параметра не задано. Подготовлено решение через взвешенную медиану с округлением числа контейнеров вверх; 500 небольших наборов сверены с перебором всех мест лаборатории. В примере вместимость 96, в основной задаче 44.

## Воспроизведение без сайта

Нужны Python 3, Node.js, `7zz` и `unrar`. Архивы сохранены побайтово в `inputs/`; они совпали с SHA-256 успешной официальной проверки, зафиксированной в [предыдущем отчёте](../ege-informatics-source-recheck-2026-11-05.json). В текущем пакете новая загрузка с ФИПИ не выполнялась. Для первоначально полученных из зеркала копий происхождение и совпадение с официальными байтами разделены в манифесте.

Из этого каталога:

```bash
python3 verify.py > /tmp/ege-remaining19-python.json
node verify-independent.cjs /tmp/ege-remaining19-python.json > /tmp/ege-remaining19-independent.json
diff -u python-review.json /tmp/ege-remaining19-python.json
diff -u independent-review.json /tmp/ege-remaining19-independent.json
```

Скрипты проверяют архивы и контрольные суммы распакованных файлов, воспроизводят перестановки и максимальные цепочки, проверяют неверный формат остальных вложений. Они не обращаются к сети, приложению или SQLite. Функции решений приведены в черновиках; параметры учебных примеров отдельно обозначены и не переносятся на основные данные.

Для публикации нужны первичное правило разрешения равенства времени либо корректные вложения. После их получения обязательны независимая предметная сверка, весь аудит раздела, API и визуальная проверка. В этом пакете публикации нет; прежние 203 теста и проверки сайта не выдаются за повторно выполненные.

Остальные 11 задач представлены ранее подготовленными [четырьмя разборами границы слова](../ege-informatics-remaining-2026-11-04/conditional-drafts.json) и [семью разборами записи скорости](../ege-informatics-transfer-review-2026-11-05/rate-conditional-drafts.json). Для них по-прежнему нужны применимые пояснения первоисточника.
