Для 22 тем найдены содержательные примеры, для одной — ограниченное подтверждение; три темы не подтверждены. Это не оценка полноты покрытия учебной программы. Для широких тем пример может охватывать только один пункт.

Часть задач уже находится в нашем банке, но под другими исходными КЭС. Ноль сейчас означает отсутствие подходящей метки в выгрузке, а не обязательно отсутствие соответствующих условий.

Как исправлять

Сначала составить и проверить дополнительное тематическое соответствие для уже загруженных задач, сохранив исходные КЭС. Реальные пробелы пополнять из первичного источника ФИПИ после сверки. Не переносить темы автоматически по совпадению слов или номеров кодов.

  • example_found означает наличие хотя бы одного задания по содержанию темы или её части, а не полное покрытие темы.
  • unconfirmed означает отсутствие подтверждения в этой проверке, а не доказанное отсутствие заданий у источника.
  • Некоторые примеры относятся к дополнительным типам Д; соответствие действующей спецификации не проверялось.
  • Число прототипов «Решу ОГЭ» нельзя напрямую сравнивать с количеством всех заданий ФИПИ.
  • Локальные примеры — содержательные соответствия, не утверждение полной идентичности условия, формул и рисунков внешним примерам.

Код приложения, счётчики, банк заданий и решения не изменялись.
