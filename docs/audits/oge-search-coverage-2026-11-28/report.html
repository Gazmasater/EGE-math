ЕГЭ ФИПИ: робот обходит решения, но поисковый охват ОГЭ остаётся проблемой

28 ноября 2026, московская дата. Анализ без изменений сайта.

Широкий пробел нельзя объяснить отсутствием решений или общим запретом обхода. Все 3884 задачи ОГЭ-математики имеют опубликованные решения. За доступные 25–27 ноября подтверждённый YandexBot получил 200 для 924 разных задач (1035 запросов). В сохранённом списке поиска нашли только 11 отдельных страниц. Это разрыв между наблюдениями, а не точная текущая доля индексации.

Что подтверждено

  • Для 57 задач последнее доступное событие — REMOVED_FROM_SEARCH / LOW_QUALITY. В каждом случае указанный обход был после публикации решения. 19 из них повторно получили 200 от подтверждённого робота уже 25–27 ноября. Повторный обход не доказывает возврат в поиск.
  • Для F1F841 причина исключения по-прежнему не получена. Задача открывается за два обычных перехода из /oge, в том числе через тему 1.2. Она первая в теме 1.2 и одиннадцатая на первой странице всех заданий; решение есть в HTML.
  • Проверены 188 публичных страниц, включая 48 отдельных задач. Везде 200, один H1, canonical на себя, index,follow. Все 11 страниц темы 1.2 содержат ровно 122 разных задания и обычные ссылки на отдельные страницы; каждая страница достижима по полученным ссылкам.
  • У всех 37 задач расширенной группы «число на прямой» свежие URL-отчёты не содержат строк; доступное окно 9–22 ноября. В группе 27 задач с дробями и 10 с корнями; исходная узкая группа с неправильными дробями — 12. Контроль F2CF43 возвращает одну строку: два показа и ноль кликов за окно.

Похожие задачи и настоящие дубли

Сравнение только текста даёт 53 группы, 464 задания. После учёта SHA-256 всех 2931 ссылок на рисунки остаются две пары: 83E501 / 77BC78 и 1506BA / 6F5EF4. У обеих совпадают структура исходного условия с MathML, байты рисунков, ответ и полный набор полей решения. Технические идентификаторы и формы ФИПИ исключены из сравнения структуры. Эти четыре страницы — отдельные кандидаты для последующего ручного решения о canonical; они не объясняют весь пробел.

У F1F841 точных дублей по тексту, условию с рисунком или полному решению не обнаружено. Массово объединять страницы с одинаковым коротким текстом опасно: разные рисунки и формулы могут задавать разные математические задачи.

Что остаётся гипотезой

F1F841 названа широкой темой «Обыкновенные и десятичные дроби, проценты, бесконечные периодические дроби»; конкретный навык — выбор дроби по точке на числовой прямой. Более точный заголовок можно проверить на ограниченной группе. Но контроль F2CF43 с тем же общим названием темы присутствует в сохранённом списке, поэтому одно название не объясняет исключение.

Черновик для проверки, пока не опубликованный: F1F841 — Какая дробь отмечена на числовой прямой? Ответ и решение | ОГЭ.

Документация Яндекса описывает малоценность/маловостребованность как автоматическое решение для конкретной страницы с несколькими возможными причинами. Этот статус сам по себе не устанавливает ограничение всего сайта. Canonical предназначен для эквивалентных страниц; он не служит универсальным исправлением для разных вариантов заданий.

    Различать получение страницы, включение, показы и клики; одновременная правка всех страниц лишит сравнение проверяемого контроля.

Ограничения и воспроизводимость

  • Список поиска и журнал содержат разнородные даты и не отражают синхронное текущее состояние индекса. 11 из 3884 — охват доступной выгрузки, а не измеренная текущая доля индексации.
  • Заново получены только первые страницы и счётчики списков поиска/событий; совпадение ответов не доказывает актуальность каждой старой строки.
  • 37 свежих адресных аналитических отчётов заканчиваются 22 ноября; отсутствие строк не устанавливает текущую причину исключения.
  • Обход подтверждён только сохранёнными логами 25–27 ноября: в них нет Host, проверка прямого и обратного DNS выполнена сейчас. Ответ 200 не устанавливает включение в поиск или его дату.
  • 188 HTTP-проверок подтверждают текущие ответы сервера, но не раскрывают HTML-копию в индексе. Все 3884 решения проверены локально, а не 3884 запросами к сайту.
  • Общие названия тем есть и у страниц из доступного списка поиска. Их роль в исключении остаётся гипотезой; уточнение заголовков не гарантирует включение.
  • Для F1F841 нет адресного события исключения. Причины 57 других задач нельзя переносить на неё. Причинная связь старых исключений с недавним спадом входов в каталоги не установлена.
