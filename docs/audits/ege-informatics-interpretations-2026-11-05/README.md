# Одиннадцать разборов неоднозначных условий

Семь задач о передаче файла рассчитаны при буквальной скорости и отдельно при гипотезе о степени двойки. Оба результата подписаны в поле ответа. Четыре задачи распределения рассчитаны при сортировке по началу, затем окончанию; это правило также указано в поле ответа. Альтернативный порядок строк разобран в решениях. Исходные условия сохранены. Это условные расчёты, не полученный официальный ключ.

Проверяемые записи и доказательства находятся в `scripts/data/ege-informatics-interpretations-*.json`. Четыре исходных ZIP без изменений лежат в `fipi-assets/ege-informatics/docs/restored-sorting/`. Прежние черновики обеих трактовок не переписаны.

Пересчёт из любой рабочей копии репозитория:

```sh
python3 docs/audits/ege-informatics-interpretations-2026-11-05/verify.py
node --test scripts/ege-informatics-interpretations.test.js
```

Python использует точные дроби и две очереди; предметный аудитор JavaScript использует BigInt и прямой перебор свободных мест. Проверяются все назначения заявок и запускается код из каждого из четырёх решений. Переносимый пересчёт сравнивает SHA-256 внешнего файла с сохранённой записью его загрузки; повторное скачивание он не выполняет.

Файл внешнего разбора №57433 совпал с 290F15 побайтно. Его сортировка даёт 344 53; другие три файла пересчитаны отдельно. Разбор №7376 подтверждает метод сравнения времени, но имеет другие параметры и не устанавливает исходное оформление наших семи скоростей.

Две задачи 1F25B2 и 7F1EAA остаются без численного ответа из-за неправильных вложений. Их развёрнутые алгоритмы и доказательства уже находятся в `../ege-informatics-remaining19-2026-11-05/conditional-drafts.json`. Необходимые данные: соответственно список размеров коробок и пары «ряд, место».

Полные артефакты публикации и резервные копии: `/root/ege-informatics-interpretations-20261105/`. Итог проверки после публикации — `report.json`.

Для двух задач с ошибочными вложениями добавлена готовая программа `missing-input-solvers.py`. Она проверяет структуру входа и отказывается вычислять выдуманный ответ по неподходящему файлу. Проверки: 500 полных переборов наборов коробок, 1023 набора занятых мест и отказ на всех трёх имеющихся неверных файлах; отчёт `missing-input-review.json`.
