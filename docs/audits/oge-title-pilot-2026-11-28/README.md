# Заголовки задач ОГЭ и поисковые входы в каталог

28 ноября 2026 года в 01:53 МСК на ege-fipi.ru опубликованы новые title и H1 для шести задач. У F1F841 в заголовке теперь виден вопрос «Какая дробь со знаменателем 19 отмечена на числовой прямой?». Знаменатель берётся из условия. Общий заголовок используется, если условие перестанет соответствовать этому вопросу или решение снимут с публикации.

Группы определены перед публикацией по соседним позициям задач в исходном каталоге. В каждой паре одна страница получила новый заголовок. Распределение зафиксировано в [pilot.json](pilot.json). Это небольшая целевая выборка с разной предысторией обхода. До начала теста Яндекс исключал по причине LOW_QUALITY одну задачу из группы с новыми заголовками (8D164C) и две из контрольной группы (7C7947 и DC38F4). У всех двенадцати в API статистики запросов отсутствовали адресные строки за 9–22 ноября. Вебмастер вернул пустой список отслеживаемых важных страниц и пустую историю для F1F841. Текущая причина её отсутствия осталась неизвестной. Ответы сервера и исходные состояния приведены в [baseline.json](baseline.json).

Предпросмотр и публичная проверка охватили обе группы, F2CF43, FDA042, каталог и тему 1.2. Проверены HTML и API, исходное условие, решение, тематические ссылки, метаданные и структурированная разметка. Новый title также используется в Open Graph и имени учебного материала. На 390 и 1280 px проверены заголовок F1F841 и переход к решению. Повторное чтение SQLite подтвердило сохранность опубликованного содержимого всех 3884 решений ОГЭ.

Метрика, поиск без технического трафика, полные московские понедельник–пятница. Отчёты по устройствам запрашивались отдельно. Приведены визиты.

| Точный /oge | 173 | 29 |
| Точный /oge, смартфоны | 114 | 22 |

У корня основной потере кликов на смартфонах сопутствовали падение позиции и сокращение показов. Три клика на подборку покрыли лишь часть потери корня. Связка «фраза, URL, устройство» за 23–27 ноября пока недоступна в обычном Вебмастере. Два запроса с явной сортировкой по 23 и 27 ноября вернули ограничение по 22 ноября. Расширенная базовая выгрузка объявляла данные по 25-е. Попытка получить данные для двух URL и повтор для одного вернули HTTP 504, идентификатор выгрузки не получен, остаток бесплатной квоты после попыток составил 100. Детализация Метрики по фразам Яндекса за 23–27 ноября также вернула пустой список при ненулевых суммарных визитах. Агрегаты и результат по трём фразам сохранены в [search.json](search.json).

## Как читать следующий замер

Ежедневно в 09:15 МСК с 28 ноября по 31 декабря включительно таймер ege-oge-title-pilot.timer запускает [сбор данных](measure.py). Даты окончания заданы календарём самого таймера. Текстовая сводка находится в /root/ege-oge-titles-20261128/measurements/latest.txt, подробные ежедневные наблюдения — в observations.json в той же папке. В репозитории лежат исходные файлы таймера и службы для воспроизведения. Первый сбор выполнен на сервере.

Первым обходом считается успешный GET точного адреса после подтверждённой публикации, с User-Agent YandexBot и проверкой прямого и обратного DNS. Обрабатываются сохранённые общие логи Nginx. Принадлежность задачи сайту определяется по точному ID, поскольку в этих логах нет поля Host. Первый найденный обход сохраняется между запусками. По каждой паре сравниваются одинаковые семь полных московских дней, начиная со следующего дня после обхода обеих страниц. Сбор сохраняет наличие URL в доступной выборке индекса и датированные события, а также показы и клики. Пустые строки и численные нули учитываются отдельно. Если обхода или полного окна статистики к окончанию наблюдения нет, у пары останется отметка ожидания. По 12 страницам можно решить, стоит ли расширять проверку.

Для /oge сбор сохраняет доступные дни 16–20 и 23–27 ноября. По мере обновления API он сопоставляет одинаковые дни недели, выделяет запросы с наибольшим снижением числа зарегистрированных кликов на корень и запрашивает адреса, показы, клики и позиции на смартфонах и ПК. Запросы поиска и технические параметры входящих ссылок исключены из разбивки адресов. Полные рабочие снимки находятся в закрытом каталоге измерений на сервере.
