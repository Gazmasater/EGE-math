Термоэлементы

Рассмотрим цепь, составленную из проводников, изготовленных из разных металлов (см. рисунок 1). Если места спаев металлов находятся при одной температуре, то тока в цепи не наблюдается. Положение станет совершенно иным, если нагреть какой-нибудь из спаев, например спай a.
В этом случае гальванометр покажет наличие в цепи электрического тока, протекающего всё время, пока существует разность температур между спаями a и b.

Рисунок 1. Цепь, состоящая из железного и двух медных проводников
и гальванометра

 

Значение силы тока, протекающего в цепи, приблизительно пропорционально разности температур спаев. Направление тока зависит от того, какой из спаев находится при более высокой температуре. Если спай a не нагревать, а охлаждать (поместить, например, в сухой лёд), то ток потечёт в обратном направлении.

Описанное явление было открыто в 1821 г. немецким физиком Зеебеком и получило название термоэлектричества; комбинация проводников из разных металлов, образующих замкнутую цепь, называется термоэлементом. Важная область применения металлических термоэлементов – их использование для измерения температуры.
