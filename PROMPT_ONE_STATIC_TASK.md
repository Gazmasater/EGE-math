Продолжи обработку задач статики в проекте ege-fipi.ru. Это один шаг автоматического конвейера: обработай ровно одну следующую задачу.

1. Прочитай STATIC_SOLUTIONS_PROGRESS.md и возьми первую задачу со статусом [~], а если таких нет — первую со статусом [ ]. Не изменяй [x].
2. Открой полное условие ФИПИ и исходный рисунок задачи.
3. Самостоятельно определи тела, силы, точки приложения, оси, плечи и моменты; реши задачу и независимо проверь расчёт, единицы, размерность и ответ.
4. Сначала выводи общую формулу, затем отдельной строкой подставляй численные данные с единицами. Индексы в тексте и SVG оформляй подстрочно и одинаково (например, ρ_воды, F_А, T_1).
5. Создай корректную inline SVG-схему с правильными направлениями сил и исходной геометрией ФИПИ. Проверь страницу и рендер скриншотом, если доступен браузер.
6. Внеси решение в реальные данные проекта тем же способом, что и существующие решения, запусти npm run audit:solutions и перезапусти сервис при необходимости.
7. Только после полной проверки поставь задаче [x] в STATIC_SOLUTIONS_PROGRESS.md и сохрани файл. Если есть настоящий технический блокер, поставь [!] и запиши конкретную причину.

Не обрабатывай вторую задачу в этом запуске и не переписывай готовые [x]. Не ограничивайся отчётом: внеси фактические изменения в проект. Перед завершением проверь git diff --check.
