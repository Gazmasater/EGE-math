# EGE Math

Локальный каталог заданий профильного ЕГЭ по математике из открытого банка ФИПИ.

## Запуск

Требуется Node.js 18 или новее.

```powershell
node server.js
```

После запуска откройте <http://localhost:8765>.

Доступные разделы: уравнения, стереометрия, неравенства, финансовая математика, оптимальный выбор, планиметрия, задачи с параметром, числа и их свойства.

Условия и связанные ресурсы сохранены локально. Подключение к ФИПИ требуется только при использовании кнопки обновления.
